# omega Global Skills Plan 1 — Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the `omega` global plugin's machinery — its manifest, the `omega-mode` tool, the three hooks that inject the mode line, the marketplace manifest, and the installer, doctor and test changes — so that every studio shim loads `shared/omega` beside the studio, a typed `/omega:<mode>` command sets a mode that survives compaction, and five placeholder-free skill stubs exist for Plan 2 to fill.

**Architecture:** `shared/omega/` is a second Claude Code plugin that every studio shim passes as a second `--plugin-dir`; in copy mode it is snapshotted to `<target>/omega` like the studio. A mode is a line in a per-session file under the config root; `bin/omega-mode` is that file's only writer and knows the line format and the rule text; `hooks/prompt-submit.sh` turns typed `/omega:*` envelopes into `omega-mode` calls and, together with `hooks/session-start.sh`, prints the `Omega modes:` block as additional context; `hooks/session-end.sh` deletes the file. Nothing in any studio is edited.

**Tech Stack:** POSIX `sh` (no bash-isms, no new dependencies; `jq` only when present), the existing `lib/common.sh` helpers and `tests/assert.sh` harness for installer code and tests, Claude Code plugin conventions (`.claude-plugin/plugin.json`, `SKILL.md` frontmatter, `hooks/hooks.json` with `${CLAUDE_PLUGIN_ROOT}`, hook JSON on stdin and `hookSpecificOutput` on stdout), a marketplace manifest at the repository root.

**Spec:** `docs/omega/specs/2026-09-13-global-skills-design.md` — this plan implements its "Delivery — 1. Foundation" scope: the sections "Packaging and loading" (plugin manifest, the shim, `doctor.sh`, marketplace manifest), "Mode mechanism" (the mode file, `bin/omega-mode`, hooks, precedence contract as carried by the stubs), and "Tests" except the per-skill text contracts. The five skill procedures, their text contracts and the README "Global skills" section are Plan 2 (`docs/omega/plans/2026-09-13-plan-2-skills.md`).

## Global Constraints

Copied from the spec; every task's requirements include these.

- POSIX `sh` only, for every script and test. No bash-isms, no new dependencies. `jq` may be used *when present* (guarded by `command -v jq`), never required.
- Everything under `shared/omega/` is self-contained: hooks and `bin/omega-mode` never source `lib/common.sh` — in copy mode the plugin root is a snapshot with nothing beside it. Every script under `shared/omega/bin/` and `shared/omega/hooks/*.sh` passes `sh -n` and is executable (`chmod +x`).
- `install.sh` never writes into `~/.claude`; `guard_target` is unchanged. Install paths contain no spaces.
- `shared/omega/.claude-plugin/plugin.json` has `name` `omega`, `version` `0.1.0` and a `description`. `shared/omega` has **no** `requires.txt` and no `settings.json`.
- Skill frontmatter: `name` equals the skill directory; `description` starts with "Use when". The five directories are exactly `handoff`, `parallel`, `local-merge`, `integration`, `autopilot`.
- The mode file is `${CLAUDE_CONFIG_DIR:-$HOME/.claude}/omega/modes/<session id>`, one mode per line: the mode name, then zero or more `key=value` pairs separated by single spaces, for example `parallel max=3`, `parallel`, `local-merge`, `integration slug=ui-rework`, `autopilot`. An empty file is deleted, never left behind.
- The session id is `--session <id>` when given, else `$CLAUDE_CODE_SESSION_ID`; hooks read `session_id` from the JSON on stdin and pass it as `--session`. Without either, `omega-mode` exits 1 with a message. A session id may contain only `A-Z a-z 0-9 . _ -`.
- The shim text is exactly:

  ```sh
  #!/usr/bin/env sh
  # Generated by omega-ai install.sh — launches Claude Code against the
  # <studio> studio's isolated config root with the studio plugin and the
  # omega global plugin loaded live.
  OMEGA_STUDIO_ROOT="<plugin dir>"
  OMEGA_GLOBAL_ROOT="<global dir>"
  export OMEGA_STUDIO_ROOT OMEGA_GLOBAL_ROOT
  CLAUDE_CONFIG_DIR="<target>" \
  PATH="<target>/bin:$OMEGA_GLOBAL_ROOT/bin:$PATH" \
    exec claude --plugin-dir "$OMEGA_STUDIO_ROOT" --plugin-dir "$OMEGA_GLOBAL_ROOT" "$@"
  ```

  where `<plugin dir>` is `studios/<studio>` in the repository (symlink mode) or `<target>/studio` (copy mode), and `<global dir>` is `shared/omega` in the repository (symlink mode) or `<target>/omega` (copy mode).
- The config root receives, in addition to what it receives today, only the copy-mode snapshot `<target>/omega`, recorded in the manifest. In symlink mode nothing of omega lives under the target.
- Hook output is one line of JSON: `{"hookSpecificOutput":{"hookEventName":"<event>","additionalContext":"<escaped text>"}}`, escaped exactly as `studios/game-dev/hooks/session-start.sh` escapes (backslash, double quote, tab; newlines joined as `\n`; carriage returns and other control characters dropped). `session-start.sh` always prints this line; `prompt-submit.sh` prints it only when at least one mode is set and prints nothing otherwise; `session-end.sh` prints nothing. Every hook exits 0 in every case it handles (a SessionStart hook exiting 2 would reset the session's context).
- `tests/omega_test.sh` runs without a config root: `omega-mode` and the hooks are pointed at a temporary `CLAUDE_CONFIG_DIR` under `mktemp -d`, and `CLAUDE_PLUGIN_ROOT` at `shared/omega`.
- Never ask the user anything; every task here has a decided answer. Never push.
- Commit messages end with these two lines:

  ```
  Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_01EXbiTV13oWT2MjvbFXAuB2
  ```

## Interfaces Plan 2 depends on

Plan 2 writes the five skill procedures against these exact names and strings. A change here is a change there.

**`omega-mode` grammar** (`--session ID` may appear anywhere on the line):

```
omega-mode [--session ID] set   <mode> [key=value ...]   add or replace the mode's line, in place
omega-mode [--session ID] clear <mode> | --all           remove one mode (the file when it empties), or the file
omega-mode [--session ID] show                           print the file's lines; nothing when no mode
omega-mode [--session ID] path                           print the mode file's path
omega-mode [--session ID] brief                          print the "Omega modes:" block; nothing when no mode
```

Exit codes: 0 ok — `show`, `brief` and `clear` exit 0 even when there is no file; 1 for a usage error, no session id, an invalid session id, an invalid mode name (`[a-z][a-z0-9-]*`, no trailing dash), or an invalid pair (key `[a-z]…`, a non-empty value, characters limited to `A-Z a-z 0-9 = . _ / : @ + -`). `omega-mode` is on `PATH` inside a studio (the shim adds `$OMEGA_GLOBAL_ROOT/bin`); in plain `claude` the SessionStart context line names its absolute path.

**Mode lines:** `parallel max=<N>`, `parallel` (unlimited), `local-merge`, `integration slug=<slug>`, `autopilot`.

**SessionStart context** — the first line is always:

```
Omega global skills: /omega:handoff, /omega:parallel [N|off], /omega:local-merge [off], /omega:integration <start|add|status|finish>, /omega:autopilot [off]. Mode tool: <absolute path>/bin/omega-mode (set | clear | show | path | brief).
```

followed, when a mode is set, by the `brief` block.

**The `brief` block** (also the whole of `prompt-submit.sh`'s context). First line `Omega modes: ` plus the file's lines joined with ` · ` (space, U+00B7, space); then one rule line per set mode, two-space indented, in file order:

```
  parallel: dispatch up to <N> ready tasks at once, each in its own worktree; review each; cherry-pick onto the feature branch; the invoking skill's bookkeeping is unchanged.
  parallel: dispatch every ready task at once, each in its own worktree; review each; cherry-pick onto the feature branch; the invoking skill's bookkeeping is unchanged.
  local-merge: skip GitHub checks; run the project's local CI; merge through gh pr merge --admin only on exit 0; PR base is the integration branch when one is set.
  integration: story branches PR into integration/<slug>; docs/integrations/<slug>.md is the set; finish only when every row is merged.
  autopilot: never AskUserQuestion — rule by the standards, log the ruling with its cost if wrong, continue; commit, push and open a PR, never merge; end with handoff.
```

(the first `parallel` line when `max=` is set, the second when it is not; `<N>` and `<slug>` are the values from the file).

**Prompt envelopes the hook acts on:** `/omega:parallel <N>` → `set parallel max=<N>`; `/omega:parallel` → `set parallel`; `/omega:parallel off` → `clear parallel`; `/omega:local-merge` / `off` → `set` / `clear local-merge`; `/omega:autopilot` / `off` → `set` / `clear autopilot`; `/omega:integration start <slug>` → `set integration slug=<slug>`. Everything else — `handoff`, `integration add|status|finish`, a non-numeric parallel argument, a foreign command, a `<scheduled-task>` prompt, plain text — leaves the file untouched. `integration finish` clears the mode from inside the skill after it succeeds, never from the hook (finish refuses while a story is unmerged, and the mode must survive that refusal).

**Skill stub frontmatter** (Plan 2 keeps these `name` and `description` values verbatim):

| Skill | `description` |
|-------|---------------|
| `handoff` | Use when a session must stop or pause mid-work (context limit, compaction, /clear) — finds a safe stopping point, commits and pushes everything, and prints the prompt that resumes the work in a new session. |
| `parallel` | Use when an approved plan has independent tasks and you want them implemented concurrently by subagents, with an optional cap on how many run at once — keeps the main session's context small. |
| `local-merge` | Use when GitHub Actions is unavailable or rate-limited — skips the remote checks, runs the project's local CI, and merges through gh pr merge --admin when it is green. |
| `integration` | Use when several related stories must land together — creates an integration branch every story merges into, tracks the set, and lands the whole set on main through the local-merge rules. |
| `autopilot` | Use when a long run must proceed with nobody at the keyboard — asks every open decision up front, commits the spec and plan, then executes without questions, logging each ruling, pushing after every task, and ending with a handoff. |

**Precedence contract** — the four mode skills (`parallel`, `local-merge`, `integration`, `autopilot`) carry this paragraph verbatim under a `## Precedence` heading; `tests/omega_test.sh` checks its first sentence:

> This mode changes how work is scheduled, saved, merged or stopped. It never removes a gate: approvals, reviewers, tests, `Verify:` rules and the invoking skill's state writes happen exactly as that skill says. It never replaces the invoking skill; that skill keeps running and this mode shapes one of its steps. When this mode and the invoking skill disagree about scheduling, merge mechanics or when to stop, this mode wins; when they disagree about a gate, the invoking skill wins.

```sh
#!/bin/sh
# Tests for the omega global plugin: manifest, skill stubs, marketplace
# manifest, omega-mode, and the three hooks. Runs without a config root:
# omega-mode and the hooks are pointed at a temporary CLAUDE_CONFIG_DIR.
set -u
REPO_ROOT="$(cd "$(dirname "$0")/.." && pwd)"
. "$REPO_ROOT/tests/assert.sh"
. "$REPO_ROOT/lib/common.sh"

OMEGA="$REPO_ROOT/shared/omega"
MODE="$OMEGA/bin/omega-mode"
TMP="$(mktemp -d)"
trap 'rm -rf "$TMP"' EXIT
CFG="$TMP/cfg"

# first_field FILE KEY — the value of a single-line "KEY: value" frontmatter
# field; empty when absent.
first_field() {
  sed -n "s/^$2:[[:space:]]*//p" "$1" | head -n 1
}

# valid_json FILE — jq when present, otherwise a shape check: first non-blank
# character '{', last '}'.
valid_json() {
  if command -v jq >/dev/null 2>&1; then
    jq -e . "$1" >/dev/null 2>&1
  else
    _first="$(tr -d '[:space:]' < "$1" | cut -c1)"
    _last="$(tr -d '[:space:]' < "$1" | tail -c 1)"
    [ "$_first" = "{" ] && [ "$_last" = "}" ]
  fi
}

test_plugin_files() {
  assert_file "$OMEGA/.claude-plugin/plugin.json" "omega has a plugin manifest"
  assert_status 0 "omega plugin.json is valid JSON" -- valid_json "$OMEGA/.claude-plugin/plugin.json"
  assert_eq "omega" "$(json_field "$OMEGA/.claude-plugin/plugin.json" name)" \
    "omega plugin.json names the omega namespace"
  assert_eq "0.1.0" "$(json_field "$OMEGA/.claude-plugin/plugin.json" version)" "omega plugin.json is version 0.1.0"
  for s in handoff parallel local-merge integration autopilot; do
    assert_file "$OMEGA/skills/$s/SKILL.md" "omega ships the $s skill"
  done
  assert_missing "$OMEGA/requires.txt" "omega declares no hard dependencies"
  assert_missing "$OMEGA/settings.json" "omega has no settings.json"
}

test_skill_stubs() {
  for s in handoff parallel local-merge integration autopilot; do
    f="$OMEGA/skills/$s/SKILL.md"
    assert_eq "---" "$(head -n 1 "$f")" "omega:$s starts with frontmatter"
    assert_eq "$s" "$(first_field "$f" name)" "omega:$s frontmatter name matches its directory"
    TESTS_RUN=$((TESTS_RUN + 1))
    case "$(first_field "$f" description)" in
      "Use when"*) _pass "omega:$s description starts with 'Use when'" ;;
      *) _fail "omega:$s description starts with 'Use when'" ;;
    esac
  done
  for s in parallel local-merge integration autopilot; do
    assert_contains "$OMEGA/skills/$s/SKILL.md" "This mode changes how work is scheduled, saved, merged or stopped." \
      "omega:$s carries the precedence contract"
    assert_contains "$OMEGA/skills/$s/SKILL.md" "omega-mode" "omega:$s sets or clears its mode through omega-mode"
  done
}

test_marketplace() {
  m="$REPO_ROOT/.claude-plugin/marketplace.json"
  assert_file "$m" "the repository has a marketplace manifest"
  assert_status 0 "marketplace.json is valid JSON" -- valid_json "$m"
  assert_eq "omega-ai" "$(json_field "$m" name)" "the marketplace is named omega-ai"
  assert_contains "$m" '"name": "omega"' "the marketplace publishes the omega plugin"
  src="$(sed -n 's/.*"source"[[:space:]]*:[[:space:]]*"\([^"]*\)".*/\1/p' "$m" | head -n 1)"
  assert_eq "./shared/omega" "$src" "the omega plugin's source is ./shared/omega"
  assert_file "$REPO_ROOT/${src#./}/.claude-plugin/plugin.json" "the marketplace source resolves to the plugin"
}

run_tests test_plugin_files test_skill_stubs test_marketplace
```

```sh
#!/bin/sh
# omega-mode — the one writer of the omega mode file.
#
#   omega-mode [--session ID] set   <mode> [key=value ...]   add or replace the mode's line, in place
#   omega-mode [--session ID] clear <mode> | --all           remove one mode, or the file
#   omega-mode [--session ID] show                           print the file's lines; nothing when no mode
#   omega-mode [--session ID] path                           print the mode file's path
#   omega-mode [--session ID] brief                          print the "Omega modes:" block the hooks inject
#
# The file is ${CLAUDE_CONFIG_DIR:-$HOME/.claude}/omega/modes/<session id>,
# one mode per line: the mode name, then optional key=value pairs. The
# session id is --session when given, else $CLAUDE_CODE_SESSION_ID (set in
# the Bash tool's environment; the hooks pass the id they read from stdin).
# An empty file is deleted, never left behind.
#
# Exit codes: 0 ok (show, brief and clear exit 0 even with no file); 1 for
# a usage error, no session id, or an invalid session id, mode name or pair.
#
# Self-contained on purpose: in copy mode the plugin root has no lib/.
set -u

usage() {
  cat >&2 <<'USAGE'
usage: omega-mode [--session ID] set <mode> [key=value ...]
       omega-mode [--session ID] clear <mode> | --all
       omega-mode [--session ID] show
       omega-mode [--session ID] path
       omega-mode [--session ID] brief
USAGE
  exit 1
}
die() { printf 'omega-mode: %s\n' "$*" >&2; exit 1; }

# --session may appear anywhere on the line. Each original argument is taken
# from the front once and, unless it is the option or its value, appended to
# the back; after the loop "$@" is the line without the option, in order.
SESSION="${CLAUDE_CODE_SESSION_ID:-}"
n=$#
i=0
while [ "$i" -lt "$n" ]; do
  a="$1"; shift; i=$((i + 1))
  if [ "$a" = "--session" ]; then
    [ "$i" -lt "$n" ] && [ -n "$1" ] || die "missing value for --session"
    SESSION="$1"; shift; i=$((i + 1))
  else
    set -- "$@" "$a"
  fi
done

[ $# -ge 1 ] || usage
VERB="$1"; shift
case "$VERB" in set|clear|show|path|brief) ;; *) usage ;; esac

[ -n "$SESSION" ] || die "no session id: set CLAUDE_CODE_SESSION_ID or pass --session <id>"
case "$SESSION" in
  .|..|*[!A-Za-z0-9._-]*) die "invalid session id: $SESSION" ;;
esac

DIR="${CLAUDE_CONFIG_DIR:-$HOME/.claude}/omega/modes"
FILE="$DIR/$SESSION"

# valid_mode NAME — lowercase letters, digits and dashes; starts with a
# letter; no trailing dash.
valid_mode() {
  case "$1" in
    ''|*[!a-z0-9-]*|*-) return 1 ;;
  esac
  case "$1" in
    [a-z]*) return 0 ;;
    *) return 1 ;;
  esac
}

# kv PAIRS KEY — the value of KEY in a space-separated list of key=value
# pairs; empty when absent. Word splitting is the point: values carry no
# whitespace (set refuses them).
kv() {
  for _p in $1; do
    case "$_p" in
      "$2="*) printf '%s' "${_p#*=}"; return 0 ;;
    esac
  done
  return 0
}

mode_set() {
  [ $# -ge 1 ] || usage
  _mode="$1"; shift
  valid_mode "$_mode" || die "invalid mode name: $_mode (lowercase letters, digits and dashes)"
  _line="$_mode"
  for _kv in "$@"; do
    case "$_kv" in
      [a-z]*=?*) ;;
      *) die "expected key=value, got: $_kv" ;;
    esac
    case "$_kv" in
      *[!A-Za-z0-9=._/:@+-]*) die "a value may use only A-Z a-z 0-9 . _ / : @ + - : $_kv" ;;
    esac
    _line="$_line $_kv"
  done
  mkdir -p "$DIR" || die "cannot create $DIR"
  _tmp="$FILE.tmp.$$"
  # Replace the mode's line where it stands so the file keeps its order;
  # append when the mode is new. awk -v processes backslash escapes, which
  # the character check above has already excluded.
  if [ -f "$FILE" ]; then
    awk -v m="$_mode" -v l="$_line" '
      $1 == m { if (!done) { print l; done = 1 }; next }
      { print }
      END { if (!done) print l }
    ' "$FILE" > "$_tmp"
  else
    printf '%s\n' "$_line" > "$_tmp"
  fi
  mv "$_tmp" "$FILE"
}

mode_clear() {
  [ $# -eq 1 ] || usage
  if [ "$1" = "--all" ]; then
    rm -f "$FILE"
    return 0
  fi
  valid_mode "$1" || die "invalid mode name: $1"
  [ -f "$FILE" ] || return 0
  _tmp="$FILE.tmp.$$"
  awk -v m="$1" '$1 != m' "$FILE" > "$_tmp"
  if [ -s "$_tmp" ]; then
    mv "$_tmp" "$FILE"
  else
    rm -f "$_tmp" "$FILE"
  fi
}

mode_show() {
  [ -f "$FILE" ] && cat "$FILE"
  return 0
}

# The rule lines are the summary of the precedence contract every mode skill
# carries; they are fixed text so the hooks never invent them.
mode_brief() {
  [ -s "$FILE" ] || return 0
  _heads="$(awk 'BEGIN { ORS = "" } NR > 1 { printf " · " } { printf "%s", $0 }' "$FILE")"
  printf 'Omega modes: %s\n' "$_heads"
  while IFS= read -r _l; do
    _m="${_l%% *}"
    _rest=""
    case "$_l" in *" "*) _rest="${_l#* }" ;; esac
    case "$_m" in
      parallel)
        _n="$(kv "$_rest" max)"
        if [ -n "$_n" ]; then
          printf "  parallel: dispatch up to %s ready tasks at once, each in its own worktree; review each; cherry-pick onto the feature branch; the invoking skill's bookkeeping is unchanged.\n" "$_n"
        else
          printf "  parallel: dispatch every ready task at once, each in its own worktree; review each; cherry-pick onto the feature branch; the invoking skill's bookkeeping is unchanged.\n"
        fi ;;
      local-merge)
        printf "  local-merge: skip GitHub checks; run the project's local CI; merge through gh pr merge --admin only on exit 0; PR base is the integration branch when one is set.\n" ;;
      integration)
        _slug="$(kv "$_rest" slug)"
        [ -n "$_slug" ] || _slug="<slug>"
        printf '  integration: story branches PR into integration/%s; docs/integrations/%s.md is the set; finish only when every row is merged.\n' "$_slug" "$_slug" ;;
      autopilot)
        printf '  autopilot: never AskUserQuestion — rule by the standards, log the ruling with its cost if wrong, continue; commit, push and open a PR, never merge; end with handoff.\n' ;;
    esac
  done < "$FILE"
}

case "$VERB" in
  set)   mode_set "$@" ;;
  clear) mode_clear "$@" ;;
  show)  [ $# -eq 0 ] || usage; mode_show ;;
  path)  [ $# -eq 0 ] || usage; printf '%s\n' "$FILE" ;;
  brief) [ $# -eq 0 ] || usage; mode_brief ;;
esac
```

Create `shared/omega/hooks/session-start.sh`:

```sh
#!/bin/sh
# SessionStart hook for the omega global plugin (startup, resume, clear,
# compact). Prints one line naming the five skills and the absolute path of
# omega-mode — plain claude has no PATH entry for it — and, when the session
# has modes set, the "Omega modes:" block from omega-mode brief. Also prunes
# mode files older than seven days: a crashed session never ran SessionEnd.
#
# Exit 0 always: on SessionStart a non-zero exit would drop the context.
# Self-contained on purpose: in copy mode the plugin root has no lib/.
set -u

ROOT="${CLAUDE_PLUGIN_ROOT:-$(cd "$(dirname "$0")/.." && pwd)}"
MODE="$ROOT/bin/omega-mode"
DIR="${CLAUDE_CONFIG_DIR:-$HOME/.claude}/omega/modes"

# The session id comes from the hook's JSON; the environment is the fallback.
# The prompt-free SessionStart JSON has one "session_id" key, and a key
# inside a JSON string would be escaped as \"session_id\", which the pattern
# (a bare quote after the name) does not match.
input="$(cat 2>/dev/null || true)"
sid="$(printf '%s' "$input" | tr '\n' ' ' \
  | sed -n 's/.*"session_id"[[:space:]]*:[[:space:]]*"\([^"]*\)".*/\1/p' | head -n 1)"
[ -n "$sid" ] || sid="${CLAUDE_CODE_SESSION_ID:-}"

if [ -d "$DIR" ]; then
  find "$DIR" -type f -mtime +7 -exec rm -f {} + 2>/dev/null || true
fi

text="Omega global skills: /omega:handoff, /omega:parallel [N|off], /omega:local-merge [off], /omega:integration <start|add|status|finish>, /omega:autopilot [off]. Mode tool: $MODE (set | clear | show | path | brief)."
if [ -n "$sid" ]; then
  block="$(sh "$MODE" --session "$sid" brief 2>/dev/null || true)"
  if [ -n "$block" ]; then
    text="$text
$block"
  fi
fi

# Escape for a JSON string exactly as the game-dev session hook does:
# backslash, quote, tab; newlines joined; carriage returns and other control
# characters dropped.
TAB="$(printf '\t')"
escaped="$(printf '%s\n' "$text" \
  | tr -d '\r' \
  | tr -d '\000-\010\013\014\016-\037' \
  | sed -e 's/\\/\\\\/g' -e 's/"/\\"/g' -e "s/$TAB/\\\\t/g" \
  | awk 'BEGIN { ORS = "" } NR > 1 { printf "\\n" } { printf "%s", $0 }')"
printf '{"hookSpecificOutput":{"hookEventName":"SessionStart","additionalContext":"%s"}}\n' "$escaped"
exit 0
```

- [ ] **Step 5: Write `prompt-submit.sh`**

Create `shared/omega/hooks/prompt-submit.sh`:

```sh
#!/bin/sh
# UserPromptSubmit hook for the omega global plugin. A typed /omega:<skill>
# command reaches the hook as an envelope, not the literal text:
#
#   <command-message>parallel</command-message>
#   <command-name>/omega:parallel</command-name>
#   <command-args>3</command-args>
#
# The hook turns the mode commands into omega-mode calls, so a typed command
# changes the mode before the model reads the skill, and then — only when a
# mode is active — prints the "Omega modes:" block as the turn's additional
# context. Any other prompt changes nothing; with no mode it prints nothing.
#
# Exit 0 always. Self-contained on purpose: in copy mode the plugin root has
# no lib/.
set -u

ROOT="${CLAUDE_PLUGIN_ROOT:-$(cd "$(dirname "$0")/.." && pwd)}"
MODE="$ROOT/bin/omega-mode"

input="$(cat 2>/dev/null || true)"
sid="$(printf '%s' "$input" | tr '\n' ' ' \
  | sed -n 's/.*"session_id"[[:space:]]*:[[:space:]]*"\([^"]*\)".*/\1/p' | head -n 1)"
[ -n "$sid" ] || sid="${CLAUDE_CODE_SESSION_ID:-}"
[ -n "$sid" ] || exit 0

# One line, with the JSON escapes for newline and tab turned into spaces, so
# the envelope tags match whether Claude Code joined them with newlines or
# not.
flat="$(printf '%s' "$input" | tr '\n\t' '  ' | sed -e 's/\\n/ /g' -e 's/\\t/ /g')"

# Unattended scheduled-task runs never change a mode.
case "$flat" in
  *'<scheduled-task'*) exit 0 ;;
esac

skill="$(printf '%s' "$flat" \
  | sed -n 's/.*<command-name>[[:space:]]*\/omega:\([a-z-]*\)[[:space:]]*<\/command-name>.*/\1/p' | head -n 1)"
if [ -n "$skill" ]; then
  args="$(printf '%s' "$flat" | sed -n 's/.*<command-args>\(.*\)<\/command-args>.*/\1/p' | head -n 1)"
  args="$(printf '%s' "$args" | sed -e 's/^[[:space:]]*//' -e 's/[[:space:]]*$//')"
  case "$skill" in
    parallel)
      case "$args" in
        off) sh "$MODE" --session "$sid" clear parallel ;;
        '') sh "$MODE" --session "$sid" set parallel ;;
        *[!0-9]*) ;;
        *) sh "$MODE" --session "$sid" set parallel "max=$args" ;;
      esac ;;
    local-merge|autopilot)
      case "$args" in
        off) sh "$MODE" --session "$sid" clear "$skill" ;;
        '') sh "$MODE" --session "$sid" set "$skill" ;;
      esac ;;
    integration)
      # Only `start <slug>` sets the mode here. `finish` clears it from inside
      # the skill after the branch has landed: it refuses while a story is
      # unmerged, and the mode must survive that refusal.
      case "$args" in
        start\ *)
          slug="$(printf '%s' "${args#start}" | sed -e 's/^[[:space:]]*//' -e 's/[[:space:]].*$//')"
          case "$slug" in
            ''|*[!A-Za-z0-9._-]*) ;;
            *) sh "$MODE" --session "$sid" set integration "slug=$slug" ;;
          esac ;;
      esac ;;
  esac
fi

block="$(sh "$MODE" --session "$sid" brief 2>/dev/null || true)"
[ -n "$block" ] || exit 0

TAB="$(printf '\t')"
escaped="$(printf '%s\n' "$block" \
  | tr -d '\r' \
  | tr -d '\000-\010\013\014\016-\037' \
  | sed -e 's/\\/\\\\/g' -e 's/"/\\"/g' -e "s/$TAB/\\\\t/g" \
  | awk 'BEGIN { ORS = "" } NR > 1 { printf "\\n" } { printf "%s", $0 }')"
printf '{"hookSpecificOutput":{"hookEventName":"UserPromptSubmit","additionalContext":"%s"}}\n' "$escaped"
exit 0
```
